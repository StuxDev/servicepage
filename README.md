# Service Page

A clean and simple placeholder page for a Stux.Dev service that hasn't been set up yet.

## Overview

This repository contains a lightweight HTML page shown in place of a Stux.Dev service that hasn't been configured yet. It points visitors back to Stux.Dev and gives them a way to get in touch.

## Features

- 📄 Simple, clean HTML structure
- ⚡ Lightweight and fast-loading
- 🎨 Ready to customize
- 📱 Responsive design
- 🚀 Deployed at [servicepage.stux.dev](https://servicepage.stux.dev)

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/StuxDev/servicepage.git
   ```

2. Open `index.html` in your browser or deploy to your hosting provider

## Customization

Edit the HTML files to:
- Update the message
- Add your branding and logo
- Customize colors and styling
- Include additional links

## Deployment

This project uses GitHub Pages and can be automatically deployed to your desired domain.

The live version is deployed at [servicepage.stux.dev](https://servicepage.stux.dev).
